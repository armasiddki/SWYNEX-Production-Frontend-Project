# SWYNEX Book Finder
  A responsive React-based book discovery web application that allows users to search for books using the Open Library API.

## Features
   - Search books by title or author
   - Fetches real-time book data from the Open Library API
   - Book covers and detailed book information
   - Author and publication year details
   - Edition information
   - Loading state while fetching results
   - Clear search functionality
   - Reusable React components
   - Error handling for failed searches or API requests
   - Responsive design for desktop, mobile screens, and tablets
   - Open Library attribution link

## Technologies Used
    - React 
    - JavaScript
    - HTML5
    - CSS3
    - Vite
    - Open Library API

## API Integration
   This project uses the Open Library Search API to retrieve book information.
   Open Library: https://openlibrary.org/
   The application uses the API to dynamically fetch and display book data based on the user's search query.
